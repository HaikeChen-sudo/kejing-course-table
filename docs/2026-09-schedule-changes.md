# 华理版 0.1.35

## 0.1.36 界面修正

调课复用新增课程页的节次滚轮和地点输入框，确认按钮使用橙色、6 dp 圆角。仅改日期或地点时保留原始时间，调整节次才改用华理标准作息；非标准时间有明确提示。

主题改为浅色基础并补全冷灰色容器角色，防止原深色主题的默认容器与深色文字重叠。日历选中态使用橙色，日期入口显示星期。开学日设置解释第一教学周与周一表头的区别，增加周中开学、开学前隐藏课程及保存重载测试。

本轮尚未修改卡片动画或快速点击过渡。手机自动点击仍被 INJECT_EVENTS 权限拒绝，不能完成同一操作的前后对比；需获取可复现录屏或操作授权后继续诊断。

当前架构仍是 Compose、ViewModel/StateFlow 和本地 JSON。此次没有更换 UI 框架或引入数据库：手机实际有 180 次课程，按日期缓存已足够；性能问题主要来自手写翻周过渡、动画状态的读取位置，以及首页遮罩。

## 课程数据

导入器继续接收连续周次。存储入口和旧文件加载时将其展开为单次课程，每次有稳定 ID 和单一周次。迁移可重复执行，不会再次拆分。课程详情中的删除和调课只针对当前这一次。

普通课程日期由开学日所在周的周一、教学周和星期计算。调课后记录 scheduledDate，日期固定；更改开学日仅移动普通课程。修改开始时间时，编辑页保留原课程时长，结束时间仍可单独修改。冲突显示提示，不阻止用户确认学校的特殊安排。

开学日通过周课表右上角“调节课表显示”里的日历设置。customStartDate 标记防止启动时学校校历覆盖用户选择。保存使用 AtomicFile，调课成功写盘后才返回上一页。

## 渲染

- 启动遮罩的透明度包住背景；标题测量坐标变化不再重启动画。
- HorizontalPager 负责翻周和手势，页面按日期索引取课程。
- 课程进度在绘制阶段读取，不再每帧重组整张卡片。
- 今日已结束课程默认折叠；同一组名称和时间做位置、字号过渡，展开后显示详情入口。
- 非标准节次时段的课程显示在周网格下方“其他时间”，避免调课后不可见。

## 验证与边界

回归覆盖迁移幂等、单次移动不影响其他课次、修改开学日、固定调课日期、越界日期拒绝、JSON 兼容及保存重载。手机升级前后对比：32 条重复规则展开为 180 次课程，原字段和总课次保持一致，ID 唯一。

目前存储仍以单个学期文件为单位。若扩展到跨设备同步、撤销历史或大量多年课程，再评估 Room。独立课次不会自动将未来导入的新课表与旧调课记录合并；导入仍沿用原有的新建/覆盖语义。

手机已验证安装、冷启动、折叠首页和调课编辑页。ADB 点击被设备 INJECT_EVENTS 权限拦截，尚无自动手势测试或跨机型帧率对比，不能据此承诺所有手机无卡顿。

参考：[Android Calendar Instances](https://developer.android.com/reference/android/provider/CalendarContract.Instances)、[Compose 性能实践](https://developer.android.com/develop/ui/compose/performance/bestpractices)。采用单次事件身份及延迟动画状态读取的策略，未接入系统日历权限。
